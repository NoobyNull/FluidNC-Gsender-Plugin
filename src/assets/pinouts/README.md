# Board pinout images

Drop board pinout images here (`.png`, `.jpg`, `.jpeg`, `.svg`, `.webp`).

The **Board Pinout** viewer in the plugin auto-discovers every image in this
folder — no code change needed to add one. The **filename becomes the label**,
so name them how you want them shown, e.g.:

- `Corgi.png`
- `Airedale.png`
- `Pendant Display.png`

Underscores/hyphens in filenames render as spaces (`corgi_v2` → "corgi v2").

These are bundled into the build, so keep them reasonably sized (a few hundred
KB each is fine; multi-MB scans will bloat the plugin).
